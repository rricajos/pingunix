# Seguridad Ofensiva (Red Team)

## Metodologia general

1. **Reconocimiento** - Recopilar informacion sobre el objetivo
2. **Enumeracion** - Descubrir servicios, usuarios, vulnerabilidades
3. **Explotacion** - Obtener acceso al sistema
4. **Post-Explotacion** - Mantener acceso, escalar privilegios, pivotar

## Secciones

- [Reconocimiento](reconnaissance/) - OSINT, escaneo de puertos, descubrimiento
- [Enumeracion](enumeration/) - Servicios, web, SMB, LDAP
- [Explotacion](exploitation/) - Web, sistema, buffer overflow
- [Post-Explotacion](post-exploitation/) - Persistencia, movimiento lateral
- [CTF](ctf/) - Writeups y cheatsheets
- [Ingenieria Social](social-engineering/) - Tecnicas y herramientas
